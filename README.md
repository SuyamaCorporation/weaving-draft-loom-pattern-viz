# 機織り ドラフト パターン ビジュアライザー

シャフト数（2-8）・タイアップ・タイアップシーケンスを入力するとウィービングドラフト（経糸/緯糸の浮き沈みパターン）をグリッドで表示するツール。

## 機能
- シャフト数 2〜8 を選択可能
- 経糸スレッディング（Threading）グリッド: 各経糸のシャフト割り当てをクリックで編集
- タイアップ（Tie-up）グリッド: シャフト×トレッドルの接続をクリックで編集
- トレッドリング（Treadling）グリッド: 各緯糸のペダル踏み順をクリックで編集
- ドローダウン（Drawdown）: 3グリッドの組み合わせから織り組織をリアルタイム描画
- プリセット: 平織 / 三枚綾 / 四枚綾 / 五枚朱子 / 八枚朱子

## 使い方
1. シャフト数・プリセットを選択するか、「描画する」ボタンを押して初期化
2. 各グリッドのセルをクリックして模様を編集
3. ドローダウンにリアルタイムで織り組織が反映される
